# trrek

Signed and notarized builds of trrek, a macOS menu bar app that turns the edges of the trackpad into single-finger controls for volume, brightness, keyboard backlight, app switching, video scrubbing and media.

Download the DMG of the latest release from [Releases](https://github.com/burakseyitkara1/trrek-releases/releases/latest), open it and drag trrek onto the Applications shortcut.

Requires macOS 26 or later on Apple silicon. trrek checks this page for new versions at most once a day; the check can be turned off in its settings.

This repository holds release builds only.
